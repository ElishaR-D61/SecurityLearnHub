# KQL Resources
If you're looking for resources to get you started or upskill in your Kusto Query Language (KQL) queries, the below resources are a great place to start.

## Github Repos
This whole repo has so many good queries, but the README.md is a great intro to KQL - [reprise99/Sentinel-Queries](https://github.com/reprise99/Sentinel-Queries/blob/main/README.md)

Also a great repo of hutning queries - [SlimKQL/Hunting-Queries-Detection-Rules](https://github.com/SlimKQL/Hunting-Queries-Detection-Rules)

A Microsoft owned repository specifically for Azure Sentinel, with some great resources but not a whole lot of instructions - [Azure/Azure-Sentinel](https://github.com/Azure/Azure-Sentinel/blob/master/README.md)

## Microsoft Resources

### Practise / Labs
**Azure Demo Lab**  - A Demo lab of Log Analytic Workspace that has a limited set of tables - [Log Analytic Workspace Lab | Azure](https://aka.ms/lademo)
**Kusto Detective Agency** - A hands-on challenge to give you practical uses of KQL [Kusto Detective Agency](https://detective.kusto.io/)  
**Try Hack Me** - Walk through modules for KQL [KQL | TryHackMe](https://tryhackme.com/module/kql)
